## Overview

An academic marketplace project for new and second-hand acoustic guitars. It demonstrates a complete catalogue-to-checkout flow using PHP, MySQL, browser JavaScript, and session-based cart state.

## Context and challenge

The project brought together account access, product browsing, cart calculations, and relational order storage. Each step had to pass the right data forward while keeping quantities, subtotals, and totals consistent.

## My contribution

As the full-stack developer, Salsabilla implemented registration and login, product catalogue and detail pages, a PHP Session cart, quantity controls, subtotal and total calculations, checkout, and storage for orders and order items.

## Implementation highlights

- Created a catalogue → cart → checkout journey.
- Stored cart state in PHP Session and updated quantities and totals.
- Used MySQL and phpMyAdmin for account, product, order, and order-item data.
- Connected server-rendered PHP flows with JavaScript-enhanced interactions.

## Outcome

The result is an academic marketplace prototype demonstrating the main commerce workflow and relational order recording. It is not described as a production store.

## Information boundary

The project did not document a payment gateway, real payment processing, or production users. No live demo or public repository URL has been verified.

## Overview

Smart Table is a front-end interface for submitting medical documents and checking structured results returned by an ML API for a health-services client. The machine-learning service was created by the back-end team; Salsabilla’s role focused on the Angular interface, API integration, and functional testing rather than model development.

## Context and challenge

The upload and submission flow needed to send documents through a REST API, then translate processed responses into a table that made the extracted information easier to inspect. This required close attention to response structure, front-end states, and coordination when the interface and endpoint behavior did not align.

## My contribution

Salsabilla implemented the result table and document upload/submission flow, integrated the API, matched response fields to the interface, carried out functional testing, debugged issues, and worked with back-end developers to resolve integration problems. Her internship work also included API integration for user login and registration.

## Implementation highlights

- Connected Angular components to the document-processing API.
- Implemented document upload and submission through the documented REST API flow.
- Mapped structured response data into a readable table interface.
- Used Swagger and Postman to inspect endpoints and support debugging.
- Collaborated with the back-end team on login and registration integration.
- Tested the front-end flow and coordinated fixes across the API boundary.

## Outcome

The documented outcome is a functional front-end workflow for inspecting ML processing results. No claim is made about clinical validation, model quality, or healthcare outcomes.

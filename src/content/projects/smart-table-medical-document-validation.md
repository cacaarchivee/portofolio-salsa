## Overview

Smart Table is a front-end interface for checking structured results produced from medical documents by an ML API. The machine-learning service was created by the back-end team; Salsabilla’s role focused on presenting and testing its output in the web application.

## Context and challenge

Processed API responses needed to be translated into a table that made the returned information easier to inspect. This required close attention to response structure, front-end states, and coordination when the interface and endpoint behavior did not align.

## My contribution

Salsabilla implemented the result table, integrated the API, matched response fields to the interface, carried out functional testing, debugged issues, and worked with back-end developers to resolve integration problems.

## Implementation highlights

- Connected Angular components to the document-processing API.
- Mapped structured response data into a readable table interface.
- Used Swagger and Postman to inspect endpoints and support debugging.
- Tested the front-end flow and coordinated fixes across the API boundary.

## Outcome

The documented outcome is a functional front-end workflow for inspecting ML processing results. No claim is made about clinical validation, model quality, or healthcare outcomes.

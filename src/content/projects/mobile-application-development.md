## Overview

A collection of separate Android academic projects: Guest Book, a GPS-based application, an accelerometer application, and a Sound Meter. They are presented as individual exercises rather than one integrated product.

## Context and challenge

The projects explored different parts of native Android development: storing local records, reading location information, responding to device motion, and working with audio-level input.

## My contribution

Salsabilla built the applications in Java with Android Studio. Across the set, she worked with SQLite persistence, GPS, accelerometer data, and sound-related device input.

## Implementation highlights

- Guest Book explored form input and local SQLite storage.
- The GPS-based application worked with device location capabilities.
- The accelerometer application responded to motion-sensor input.
- Sound Meter explored sound-level input within an Android application.

## Outcome

Together, the projects demonstrate hands-on exposure to native Android development, local storage, and multiple device sensors in an academic setting.

## Information boundary

No Play Store listings, production-user claims, or sensor-accuracy measurements are documented. The applications are not presented as a single product.
